4-Week Execution Plan
Week 1: Infrastructure, Data Curation & Wireframing
Role 1 (Project Lead & Backend Infrastructure Engineer)
•
Create and verify the Meta Developer Account and App container (CommandIA-Test).
•
Set up a test Facebook Business Page and linked Instagram Professional Account.
•
Initialize the backend project repository using Python (FastAPI).
•
Design and deploy the Supabase PostgreSQL database schema (Merchants, Products, Orders).
Role 2 (AI / NLP & Data Engineering Specialist)
•
Execute comment/DM scraping scripts across public Algerian e-commerce social posts using
instaloader or web scraping tools.
•
Curate a 50-entry "Golden Dataset" in Google Sheets mapping raw customer inputs (in Darija,
Franco-Arabic, French, and English) to expected JSON outputs.
•
Draft the V1 System Prompt for the LLM engine defining dialect rules and commercial
guardrails (e.g., no unauthorized discounts).

Week 2: Pipeline Development & High-Fidelity Design
Role 1 (Project Lead & Backend Infrastructure Engineer)
•
Build the FastAPI webhook endpoint to verify and receive live Meta Graph API webhook
payloads (GET/POST).
•
Implement local tunneling (ngrok) to test live incoming DMs from Instagram.
•
Build the Supabase database connector to write structured JSON order payloads directly to the
Orders table.
Role 2 (AI / NLP & Data Engineering Specialist)
•
Implement the LLM engine integration using Python (OpenAI or Anthropic APIs).
•
Enforce strict JSON output parsing using Pydantic or Instructor for the 5 Sacred Fields:
–
customer_name
–
phone_number (Validated 10-digit Algerian format)
–
wilaya (Official 58 Wilayas)
–
delivery_type (HOME vs. DESK)
–
address (Commune / Street / Bureau details)
•
Test prompt iterations against the "Golden Dataset" to refine handling of haggling and missing
fields.
Role 3 (UI/UX & Media Design Specialist)
•
Convert low-fidelity wireframes into high-fidelity Figma visual designs.
•
Integrate custom branding, Algerian localizations (Wilaya/Commune selectors, delivery type
badges), and dark/light UI components.
•
Design visual components for the 5 Sacred Fields display within the orders management view.
Week 3: End-to-End System Integration & Pitch Preparation
Role 1 (Project Lead & Backend Infrastructure Engineer)
•
Connect the FastAPI Webhook pipeline directly to the AI Engine and Supabase database.
•
Conduct end-to-end integration testing: send live DMs from test Instagram accounts and
confirm automated DB records.
•
Implement exception handling for edge cases (unsupported formats, API drop-outs, incomplete
data).
Role 2 (AI / NLP & Data Engineering Specialist)
•
Fine-tune the conversational state machine logic (State 0: Inquiry → State 1: Intent → State 2:
Data Collection → State 3: Final Confirmation).
•
Implement human handoff triggers (flagging chats requiring manual intervention in the
database).
•
Prepare the technical demonstration environment for video capture.

System Interface & Data Contract
To ensure independent development between Backend, AI, and Design, all components must align
on this exact JSON schema:
{
  "order_id": "uuid-v4",
  "customer_name": "String",
  "phone_number": "String (10 Digits: 05/06/07...)",
  "wilaya": "String (1-58)",
  "delivery_type": "Enum ('HOME', 'DESK')",
  "address": "String (Commune / Location Details)",
  "product_details": {
    "item_id": "String",
    "quantity": "Integer",
    "size_color": "String"
  },
  "total_price_da": "Float",
  "order_status": "Enum ('PENDING_CONFIRMATION', 'CONFIRMED', 'REQUIRES_HUMAN')"
}
